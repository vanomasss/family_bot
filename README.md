# 🤖 Telegram Family / Reminder Bot

Асинхронный Telegram-бот для планирования задач и отложенных напоминаний.

## 🛠 Технологический стек
* **Python 3.11+**
* **Aiogram 3** — асинхронный фреймворк для Telegram API
* **APScheduler / Datetime** — планировщик задач и управление таймерами
* **Aiohttp / Webserver** — фейковый веб-сервер для Keep-Alive
* **Render & UptimeRobot** — деплой в облаке и мониторинг 24/7

## 🚀 Функционал
- ⏰ Установка отложенных напоминаний.
- 🌐 Автоматическая поддержка активности сервера (без "холодного старта").
- 🔄 Интеграция с Render (автоматический деплой при push в `main`).

## 🔧 Локальный запуск
1. Клонировать репозиторий:
   `git clone https://github.com/твой-логин/твой-проект.git`
2. Установить зависимости:
   `pip install -r requirements.txt`
3. Создать `.env` файл и добавить `TOKEN=your_bot_token`
4. Запустить:
   `python main.py`
